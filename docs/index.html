The proposal

One visible nudge, instead of one more notification.

Calendar pop-ups are small, silent and easy to swipe away. Meetwing replaces them with something you notice once, read in two seconds, and then forget about.

Problem

Meetings arrive unannounced

Banner notifications get dismissed on reflex, and a deep-work screen hides everything else. People join late or scramble in the last minute.

Proposal

A jet that carries the message

Ten and five minutes before, a jet flies in with a card: when it starts, what it is, and where it came from. It hovers long enough to read, then leaves.

Outcome

On time, still in flow

You get the heads-up without a window stealing focus. One shortcut joins the call, and Rest silences everything when you need quiet.

Proposal details

Exactly what you get.

Platforms
Windows 10 and 11 (installer and portable .exe), macOS (.dmg for Intel and Apple silicon), Ubuntu and other Linux (.deb and AppImage).
Reminders
Hand-made: title, time, optional note, once / every day / weekdays / every week, flying at that time or ahead like a meeting. From calendars (optional): any iCal (.ics) or webcal link, with recurring events, time zones and cancellations handled. All-day events are ignored.
Sources
Google Calendar, Outlook and Microsoft 365, Apple iCloud and other iCal feeds. Meetings booked through Calendly or Cal.com are labeled with their name on the card.
Flight controls
20 flight colors with a live preview, plane size, lead times, time on screen (5 to 20 seconds), direction, which display, optional soft whoosh sound, start at login.
Shortcuts
Nudge and Join work from anywhere. Rest and settings live in the tray or menu-bar icon.
Privacy
No account and no cloud. Calendar links work like passwords, so they are stored encrypted with your system keychain. The only network traffic is fetching your own calendar link.
Requirements
A desktop running Windows, macOS or Linux. For source builds, Node.js 20 or newer.

Good to know: builds are not code-signed yet. macOS shows a Gatekeeper warning on first open (right-click the app, then Open) and Windows SmartScreen may ask you to confirm (More info, then Run anyway). On GNOME, tray icons need the AppIndicator extension.

Install

Pick your system.

  1. Get the code and install the dependencies (Node.js 20+ and git required).
  2. Build the package for your system.
  3. Install the .deb (recommended on Ubuntu 24.04), or run the AppImage.
git clone https://github.com/jaisudhakar/meetwing.git cd meetwing && npm install npm run dist:linux sudo apt install ./dist/Meetwing-*-linux-amd64.deb

To try it without installing: npm start. The AppImage may need --no-sandbox on Ubuntu 24.04, which is why the .deb is preferred.

  1. Get the code and install the dependencies on the Mac.
  2. Build the .dmg, then open it from the dist folder and drag Meetwing to Applications.
  3. First launch: right-click the app, choose Open, and confirm the unsigned-app prompt.
git clone https://github.com/jaisudhakar/meetwing.git cd meetwing && npm install npm run dist:mac

Meetwing appears in the menu bar. No microphone or screen-recording permission is needed.

Questions

Before you ask.

Do I need a calendar?

No. You can add reminders by hand with a title and time. A calendar link is optional and only saves you retyping meetings.

Will the jet get in the way of my work?

No. It is a transparent window that ignores the mouse and never takes keyboard focus, so you can keep typing and clicking while it flies.

How do I find my calendar link?

In Google Calendar, open the calendar's settings and copy the secret address in iCal format. Outlook, iCloud and others offer a published ICS or webcal link. Settings inside Meetwing lists where to look.

What if I'm presenting or need quiet?

Use Rest from the tray or menu bar: one hour, until tomorrow, or until you resume. Reminders that fall inside a rest period are skipped, not replayed afterwards.

Does it work with several monitors?

Yes. The jet appears on the screen your mouse is on, or always on your main screen if you prefer.

Where is my data?

On your computer. Reminders and settings are stored locally, and calendar links are encrypted with your system keychain. Meetwing only contacts your calendar's server.
