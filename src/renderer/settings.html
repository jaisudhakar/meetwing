    Calendars

      Where do I find the link?
      • Google Calendar: Settings → your calendar → Integrate calendar → Secret address in iCal format.
      • Outlook / Microsoft 365: Calendar settings → Shared calendars → Publish a calendar → ICS link.
      • Apple iCloud: Calendar → share calendar → Public Calendar → copy the webcal link.
      • Calendly: connect your Google/Outlook calendar in Calendly; bookings then appear in that feed, and Meetwing labels them “Calendly”.

      These links work like passwords. Meetwing stores them encrypted on this computer and only contacts the calendar server.
